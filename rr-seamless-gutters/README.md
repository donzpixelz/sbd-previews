# R&R Seamless Gutters — SBD migration-demo preview

Independent static Astro modernization demo based on the public R&R Seamless Gutters, LLC GoDaddy site. The app is scoped to `/rr-seamless-gutters/` and is assembled with the other SBD previews by the repository-root build.

The preview is intentionally noindexed. The quote form is demo-only and does not submit anywhere. Public project imagery is referenced from the existing R&R GoDaddy-hosted site; the source site and all R&R-owned systems remain untouched.
