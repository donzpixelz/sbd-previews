# Lakeshore Littles — independent Astro migration preview

Run `npm install && npm run build` in this directory. Astro outputs static pages in `dist/`, scoped under `/lakeshore-littles/` through the Astro base setting. Deploy using Cloudflare Pages with root directory `lakeshore-littles`, build command `npm run build`, output `dist`. The preview remains unofficial and intentionally non-indexed; never accept transactions. Images reference publicly served Wix media and need owner authorization and local transfer before production cutover. The existing Wix and Square systems remain untouched.
